# The book at a glance

This document collects the plan of the textbook *From First Courses to the Modular Degree* and the outline of every chapter, as they stand on 15 October 2026. The outlines are the specification from which each chapter is to be written; nothing in them is final text. Instructions for continuing the work are in the repository file `CONTINUE.md`.

Each outline lists the chapter's core results in teaching order (definitions, theorems, lemmas, examples), each with a precise statement, the planned level of rigour (proved here, proof sketched here, stated with reference), a reference, and the place where the paper uses it; then a section plan with target lengths, a coverage table, exercises, dependencies, notes for the writer, and points about the paper found while outlining.

Planned lengths are guidelines, not caps (decision D2): the book is for online reading and reference, so a chapter may run longer where that makes an explanation clearer. At about 50 lines per page the book will run to roughly 1,100 to 1,400 pages.
