# Final versions

* `paper/note.tex`: the corrected research note "Local factors of the adjoint L-function and the l-adic valuations of the
  modular degree" (D. Soni). Build: `cd final/paper && latexmk -pdf note.tex`.
* `book/`: the companion book, aligned with the corrected note (it reads the note as a single version). Build:
  `final/book/tools/build.sh` (output `final/book/build/main/main.pdf`).

The working copies at the repository root (`paper/`, `chapters/`, `important/`) keep the full history of the review,
including the list of corrections made to the earlier versions of the note.
